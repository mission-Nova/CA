CA Final AIR-1 Wolf RPG Timer + Travel + Routine PWA Package

What is new in this build:
- Dual Pomodoro modes: Lecture Session and Deep Study Session.
- Lecture mode runs in the background while you watch lecture and auto-saves as Lecture time.
- Deep Study mode starts only with fullscreen lock and pauses if fullscreen exits.
- Daily Travel Command added to Time Management.
- Daily Routine Command added to Time Management.
- Study hours exclude Sleep, Travel, Routine, and Leakage.
- Timeline shows Lecture, Travel and Routine with separate colors.

Install:
1. Extract this ZIP.
2. Upload all files/folders to your GitHub repository root.
3. Enable GitHub Pages from Settings > Pages.
4. Open your Pages URL with ?v=wolf-rpg-timer-travel-routine-1.
5. Remove old installed app from tablet home screen, then install again.
